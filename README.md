
# ☕ Advanced Java Lab

A collection of Advanced Java laboratory experiments and a Java-based project, created as part of the B.Tech Computer Science and Engineering curriculum at **Global Institute of Technology (GIT), Jaipur**.

This repository contains practical implementations of Java GUI development, client-server programming, Remote Method Invocation (RMI), Servlets, JSP, and a complete Java project.

## 📚 Experiments

| Experiment | Topic | Description |
|---|---|---|
| Experiment 1 | Calculator using MVC | A calculator implementation using separate model, view, and controller Java classes. |
| Experiment 2 | Student Registration | A Java-based student registration application. |
| Experiment 3 | Client-Server Programming | Demonstrates communication between a client and a server using Java networking. |
| Experiment 4 | Remote Method Invocation (RMI) | Demonstrates remote method calls between Java applications. |
| Experiment 5 | Java Servlets | Introduces server-side programming using Java Servlets. |
| Experiment 6 | HTML to JSP | Demonstrates the integration of HTML and JavaServer Pages (JSP). |

## 🚀 Additional Java Project

### 🛍️ ShopSphere — Java-Based Shopping Application

## 🛠️ Technologies

- **Programming Language:** Java
- **GUI Development:** Java Swing
- **Web Technologies:** Java Servlets, JSP, HTML
- **Networking:** Java Client-Server Programming
- **Distributed Computing:** Java RMI
- **Development Tools:** JDK and a Java-compatible IDE

## ⚙️ Requirements

To work with these experiments, you may need:

- Java Development Kit (JDK)
- An IDE such as Eclipse IDE or Visual Studio Code with Java support
- A servlet container, such as Apache Tomcat, for Servlet and JSP experiments
- Any additional database or library dependencies required by an individual experiment

## ▶️ How to Run

1. Clone or download this repository.
2. Open the required experiment folder or Java project in your IDE.
3. Configure the appropriate JDK and any required dependencies.
4. Review the source files and identify the main class or web application entry point.
5. Run the Java application, or deploy the web application to a compatible servlet container where required.

**Note:** The exact setup and execution steps may differ between experiments. Follow the configuration requirements of the individual project.

## 🎯 Learning Objectives

- Understand Java Swing and the MVC architecture.
- Develop basic Java GUI applications.
- Learn client-server communication using Java networking.
- Understand distributed applications using RMI.
- Explore server-side Java programming using Servlets and JSP.
- Organize, execute, and maintain Java laboratory programs using Git and GitHub.
